# Sources and claims — accessed November 11, 2026

## Competitor observations

These are observations of providers' own sites, not rankings or endorsements. No copy, imagery, prices, reviews or credentials were reused.

| Source | Observation and application |
| --- | --- |
| [Clearview Ottawa](https://clearviewottawa.ca/services) | Commercial price factors and residential scope inclusions are distinct. This build makes cleaning scope and frequency/access questions explicit, without copying prices. |
| [Mr. Glass](https://mrglass.ca/) | Dedicated glazing categories and repeated quote actions; the retrieved page also exposed unresolved template shortcodes. This build uses direct service routes and checks generated output, without invented project galleries. |
| [Centennial](https://centennialwindows.com/) | Product-type navigation and location-qualified consultation form. This build separates installation/replacement intent and asks for city/region; no manufacturer, award or warranty claims are adopted. |
| [Squeaky Cleaning](https://www.squeakycleaning.ca/) | Visible call/quote routes and extensive service/locality navigation, within a broader cleaning business. This build keeps contact actions visible with a smaller, evidence-based coverage structure. |
